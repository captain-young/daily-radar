对齐。三层的重量全压在 real-time 这一个差异点上，没有一层跑偏。

tagline 只有 6 个词，唯一的差异点是 in real-time，全句重量都在那三个字上。

划界句用 all inside the same run 把纯 observability 那一片地盘划走了——潜台词是「别人只观察完把问题丢回给你」。注意差异化是靠「别人到哪就停了」来定义的。

封面图直接把 tagline 印成主视觉，没有另起一套说法。

顺带一个 PH 的结构性现象：产品级 tagline 和本次 launch 的 tagline 是两层，经常不一致。同榜的 Cekura 产品级写「Automated QA for Voice AI」，launch 写「The self-improvement loop for voice agents」——前者是功能描述，后者在造新概念。两层打架本身就是素材。

③它按什么收钱？价值单位是什么？

能拿到的唯一定价证据在首评末尾：

送 1,000,000 free agent steps

先想：他为什么选 step 当免费额度的单位，而不是天数或席位？

按用量。价值单位是 agent 运行的 step 数。

免费额度用什么计量，就等于宣布价值随什么线性增长。给「100 万 step」而不是「3 个月」或「5 个席位」，是在说：你的 agent 跑得越多，我值越多钱。

对照另两种选法：按人（席位）适合价值来自协作的工具；按结果（成功拦下一次故障收一次钱）激励最对齐但最难计量。选按用量意味着它赌客户的 agent 调用量会涨。

本期未取到官网定价页，第 ③ 问只用了首评里的免费额度作证据。

④下面 6 条评论，哪几条是真信号？哪条是打在方法论根基上的质疑？

1 · Stefan Knight：我不会把学步的孩子一个人留在家里，那为什么会把 agent 部署上线之后就不管了。

2 · Ben Lang：恭喜团队。

3 · Abdullah Javaid：我的 agent 三次里有一次报成功，但页面其实根本没更新。你能不能校验外部副作用——页面真的变了、那行数据真的写进去了——而不是只给运行记录打分？

4 · Gal Dayan（做语音 agent）：对我们来说 time-to-respond 比正确性更重要，客户在静默里就把电话挂了。你能把每轮延迟当成独立的质量维度吗？

5 · Flavio Riper：你有没有把每次判定绑定到具体的 evaluator 版本和它用的证据？

6 · Reda Roqai Chaoui：哪类 agent 收益最大——客服、写代码、还是做研究？

3 和 4 是真购买信号；5 是根基质疑；2 是零信息；1 只有共鸣；6 暴露定位没讲清。

3、4 是真购买信号：两条都带了自己的场景和数字。「三次里有一次」是他在自己系统上量出来的；「客户在静默里挂电话」是他每天在处理的事。带自己数据的追问，意味着对方已经在心里试用过一遍了。

5 是根基质疑：评估器自己变了的时候，怎么区分是 agent 退化还是评估退化。这一条答不好，整个产品的可信度归零——所有 AI 评估类产品都绕不过「谁来评估评估器」。

2 是零信息，跳过。所有 congrats / love it / 恭喜都属于这类，不要花时间读。

1 有共鸣但没有自己的数据：类比讲得漂亮，可它没告诉你他的 agent 出过什么问题。中等信号，不是买单信号。

6 是症状不是问题：他对不上自己的号，说明产品定位没写清。出现这种提问别怪用户，是文案漏了。
